OctetLedger 0.11.1 improves collector process detection and startup diagnostics for portable packages installed by WinGet or a browser.

## Fixes

- **Startup diagnosis for marked downloads.** If the background collector fails to launch and the executable has a Windows download zone mark, the error includes its resolved path. Collector registration and startup preserve the mark so Windows can apply its configured protections.
- **Portable alias identity.** WinGet installs the command alias as a symlink to the package executable. Collector identity resolves that link when matching the running worker and its saved identity during startup, stop, and uninstall.

## Install or upgrade

Choose the Windows x64 or ARM64 ZIP, compare its SHA-256 with the matching checksum asset, extract it, and run **install.cmd**. Automatic collection requires Windows Script Host with VBScript enabled.

WinGet portable users: run `octetledger collector install` once after installing or upgrading. The previous 0.3.0 → 0.11.1 upgrade path is preserved: SQLite data and settings are kept, and the database migrates from schema 0 to schema 6.

If Windows blocks a marked executable, verify the official ZIP’s SHA-256 and compare the reported executable with the one in that ZIP. Use Windows’ approval for that file if available, or contact your administrator.

OctetLedger 0.11.1 retains SQLite schema 6 for existing 0.11.0 databases; no migration is required.
