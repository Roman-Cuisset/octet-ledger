OctetLedger 0.11.0 improves traffic accounting, the local dashboard, and recovery on Windows.

## What changed

- Concurrent collectors sample and store counters in order. Late samples cannot overwrite a newer baseline, and a renamed Wi-Fi or Ethernet adapter is less likely to be mistaken for a virtual adapter.
- Automatic SQLite retention archives older minute records by day and preserves historical totals. Per-application ETW captures assign each event to its own UTC hour.
- The local dashboard distinguishes unmeasured days from measured zero traffic in all three chart modes. It adds keyboard navigation and better narrow-screen layout, and restricts requests to its advertised loopback address. All-time reports and dashboard data load faster on the benchmark database.
- Installation and rollback use bounded waits and recover from brief Windows file locks. SQLite restore protects an open database and any remaining journal files.

## Install or upgrade

Choose the Windows x64 or ARM64 ZIP, compare its SHA-256 with the matching checksum asset, extract it, and run **install.cmd**. Automatic collection requires Windows Script Host with VBScript enabled.

Upgrading in the same Windows profile preserves the SQLite database and settings. The ZIP upgrade paths from 0.3.0 and 0.10.1 were exercised with existing data. Keep a database backup before upgrading. OctetLedger 0.11.0 retains SQLite schema 6 for existing 0.10.1 databases.
